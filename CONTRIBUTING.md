# Como contribuir

1. Abra uma issue descrevendo problema, fonte e resultado esperado.
2. Mantenha fato, métrica e editorial separados em código e interface.
3. Adicione testes para mapeamentos e fórmulas.
4. Rode `make lint test`.
5. Assine os commits com DCO: `git commit -s`.

Correções de dados precisam apontar a fonte oficial. Mudanças editoriais precisam de justificativa e histórico público.
